صفحة المنتج مع الصور الخمس ونموذج COD، بدون واتساب. Snapchat Pixel ID موجود ويسجل PAGE_VIEW.

تم إعداد Code.gs لجدول Google Sheets الذي أرسلته، ومعرّف الجدول مضاف مسبقًا. يسجل الطلبات وفق عناوين الأعمدة في ملف Excel. تأكد من أن اسم ورقة البيانات Feuil1 وأن الصف الأول يحتوي العناوين نفسها.

خطوات الربط لمرة واحدة:
1) افتح script.google.com وأنشئ مشروعًا جديدًا.
2) الصق محتوى Code.gs واحفظه. معرّف الشيت مضاف مسبقًا.
3) اختر Deploy > New deployment > Web app. اختر Execute as: Me وWho has access: Anyone ثم Deploy، ووافق على صلاحيات Google. هذا ينشر نقطة استقبال الطلبات فقط، ولا يجعل ملف الشيت عامًا.
4) تم إدخال رابط Web app الذي أرسلته داخل app.js.
5) ارفع مجلد araby-multi-landing كاملًا للاستضافة. جرّب النموذج بطلب واحد بعد النشر.

العروض: 198 / 294 / 376 ريال. يرسل النموذج الاسم والهاتف والعنوان والباقة، ويخزن النظام كذلك رابط الصفحة ووسوم UTM إن وجدت. لا يسجل Pixel حدث PURCHASE لأن طلب COD لا يعني أن البيع تم تسليمه.
